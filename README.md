# go-todo
Go-todo is a simple CLI utility that helps you keep track of tasks. You can set deadlines to make sure you finish them on time. Completely written in Go.

### Context
This is mostly just a learning project. I wanted to use Go for a future project idea I have so I decided to use this as a means to familiarise myself with the language. There are still lots of idiosyncracies I need to get into grips with but I'm enjoying the process. That's about it.

### Usage

```
Create Task: go-todo -c [Task Name]
Finish Task: go-todo -f [Task Name]
Remove Task: go-todo -r [Task Name]

List All Tasks: go-todo -l
```
